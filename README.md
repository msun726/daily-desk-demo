# Daily Desk — Interactive Demo

An interactive desktop-style productivity dashboard with sample projects, dated tasks, a calendar, and a fixed aurora photo background.

## Try it

[Open the live demo](https://msun726.github.io/daily-desk-demo/)

Choose a calendar date, complete a task, create a project, or add your own sample task. Use **Reset sample tasks** to start again. Changes are stored in your browser only; there is no account or shared task database.

## Features

- Calendar-linked daily task list and deadline overview
- Collapsible project folders and completion progress
- Task creation, editing, completion, and deletion
- Fixed-height cards with internal scrolling
- Export and import of task backups
- Fullscreen mode and external app shortcuts
- Independent demo storage, separate from the personal workbench

## Run locally

Open `index.html` in a browser. Keep `aurora.jpg` in the same folder. No dependency installation or build step is required.

## Project context

Built with AI assistance, then iteratively refined through hands-on user feedback about task organization, navigation, visual comfort, and desktop use. This public repository contains the demonstration version and sample data only.
